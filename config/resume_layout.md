# Resume Layout — v7.2 Final

This file is authoritative for resume rendering.

## Font

Use Calibri throughout.

Fallback only if Calibri is genuinely unavailable:

Arial.

## Header

Candidate name:

- Calibri Bold
- 14 pt
- centered
- no title/headline beneath it

Contact row:

- Calibri
- approximately 10 pt
- centered
- exactly ONE line

Format:

PHONE | EMAIL | LINKEDIN | GITHUB

Do not include candidate location in the standard contact row unless
explicitly configured to do so.

Do not place contact information in a document header/footer.

Do not allow the contact row to wrap.

## Margins

Use compact traditional resume margins approximately:

Left:   0.38-0.40 in
Right:  0.38-0.40 in
Top:    0.30-0.35 in
Bottom: 0.28-0.35 in

Do not use unnecessarily wide margins that make the page look sparse.

## Main Section Headings

Use:

EDUCATION
PROFESSIONAL EXPERIENCE
PROJECTS
SKILLS

Formatting:

- Calibri Bold
- 12 pt
- uppercase
- left aligned

Directly beneath each heading, use a thin black horizontal divider:

approximately 0.5 pt.

Use an ATS-safe paragraph bottom border or CSS border-bottom.

Never use a floating graphical line shape.

## Education Layout

Prefer compact horizontal use of space.

Institution/location on the left.

Dates on the same line, right aligned when possible.

Degree / GPA on the next line.

Coursework may use one compact line when relevant and approved.

Avoid unnecessary blank lines between education entries.

## Professional Experience Layout

Prefer a compact one-line entry header when possible:

ROLE | COMPANY | LOCATION                     DATES

Use:

- role/company: Calibri Bold
- supporting location/date text: approximately 10 pt
- dates right aligned using a normal tab stop, not tables

Do not create a separate location/date line unless necessary for readability.

## Project Layout

Project title:

- Calibri Bold
- approximately 10.75-11 pt

Technology descriptor:

- Calibri Italic
- approximately 10 pt

Place technology descriptor on the same line as the project title when it fits
cleanly.

Otherwise use one compact line immediately below the title.

## Body Bullets

Use:

- Calibri
- 10.5 pt minimum
- approximately single spacing

Never reduce bullet text below 10.5 pt.

Keep bullet indentation compact.

Normally use 1-2 rendered lines per bullet.

Three lines are acceptable for technically valuable content.

## Selective Bold

Use real text bolding.

Normally 1-3 meaningful bold spans per substantive Experience/Project bullet.

Prioritize:

- system/accomplishment;
- important technology/method;
- scale;
- metric;
- outcome.

Do not bold whole bullets.

## Skills

Use approximately 10.25-10.5 pt Calibri.

Keep Skills compact, typically around four lines.

## Vertical Density

Use compact but readable spacing.

Avoid large gaps between:

- contact and Education;
- section heading and first entry;
- job entries;
- project entries;
- Skills lines.

The resume should look deliberately full rather than sparse.

Do not create empty space simply because minimum content has already been met.

Use meaningful approved content to occupy available space.

## Underfill Strategy

If substantial page space remains, fill it in this order:

1. add a valuable fourth bullet to the most relevant Professional Experience;
2. add a strongly relevant approved dynamic third project with ~2 bullets;
3. strengthen overly short existing bullets with useful approved technical
   context;
4. add approved relevant coursework/detail if genuinely useful.

Do not use filler.

Do not add generic soft skills.

Do not enlarge fonts merely to fill space.

## Overflow Strategy

If the page exceeds one page:

1. remove repeated wording;
2. remove duplicate technology mentions;
3. shorten low-value phrases;
4. tighten descriptor lines;
5. tighten spacing slightly;
6. remove optional third project;
7. remove optional fourth Experience bullet.

Never shrink body text below 10.5 pt.

## ATS Safety

Single column.

No:

- layout tables;
- sidebars;
- text boxes;
- icons;
- graphics;
- photos;
- QR codes;
- skill bars;
- critical information in headers/footers.

Disable discretionary hyphenation where practical.

All visible content must remain normal extractable PDF text.


# v7.3 Deterministic Page Density

The final one-page resume should normally occupy approximately 92-96% of the
usable vertical page area.

Target visible whitespace after the last content:

approximately 0.25-0.50 inch.

More than approximately 0.5 inch of usable blank space beneath the final
section is underfilled.

If underfilled, add approved substantive content rather than enlarging fonts,
margins, or spacing.

Preferred recovery:

1. third relevant approved project;
2. 2-3 bullets for that project;
3. compact relevant coursework;
4. additional approved Experience evidence.

Keep body text >=10.5 pt.
